# Security reports

Send suspected vulnerabilities privately to **contact@firmory.ai**, the contact listed in the plugin manifest. Use the subject “Firmory plugin security report”. Do not post credentials, customer data, or exploit details in a public issue.

Include the affected plugin version or commit, client version, a description of the impact, and reproduction steps using synthetic or redacted data. If credentials were exposed, revoke them through the issuing service.

This repository distributes a preview plugin package. Cloud MCP authentication, workspace isolation, and file visibility require validation before release. No security audit or production-readiness claim is implied by package installation or schema validation.

For non-sensitive installation and documentation problems, use [GitHub issues](https://github.com/DepsilonAI/firmory-plugins/issues/new/choose).
